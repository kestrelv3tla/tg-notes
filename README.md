# tg-notes

Маленький скрипт, который превращает JSON-экспорт чата из Telegram Desktop в Markdown-заметки: один файл на день (`YYYY-MM-DD.md`), внутри сообщения по времени.

Только стандартная библиотека Python 3, ничего ставить не надо.

## Почему

Складываю заметки из избранного (Saved Messages) — идеи, ссылки, куски конфигов, которые кидаю себе с телефона. Через пару месяцев там каша и найти что-то нереально. Раз в неделю выгружаю чат, прогоняю через скрипт и кладу результат к остальным заметкам в Obsidian. Теги вида `#idea` в сообщениях помогают потом вытащить только нужное.

## Как выгрузить чат из Telegram Desktop

1. Открыть нужный чат (например, «Избранное»).
2. Меню `⋮` справа сверху → **Экспорт истории чата**.
3. Снять галочки с фото/видео/файлов, если нужен только текст.
4. Формат — **Машиночитаемый JSON**.
5. Выбрать папку и нажать **Экспортировать**. В папке появится `result.json`.

## Использование

```bash
# всё подряд, заметки лягут в ./notes
python tg_notes.py --input result.json

# своя папка
python tg_notes.py --input ~/Downloads/ChatExport/result.json --output-dir ~/vault/tg

# только то, что после 1 ноября
python tg_notes.py --input result.json --since 2026-11-01

# только сообщения с #idea (решётку можно не писать)
python tg_notes.py --input result.json --tag idea
```

Попробовать без своего экспорта:

```bash
python tg_notes.py --input examples/sample_export.json --output-dir /tmp/tg-demo
```

Если файла нет, JSON битый или структура не та — скрипт пишет короткую ошибку и выходит с кодом 1.

## Что учитывается

- берутся только записи с `"type": "message"` (служебные вроде закрепов пропускаются);
- поле `text` бывает строкой или списком кусочков (ссылки, жирный текст и т.д.) — оба варианта склеиваются в обычный текст;
- пустые сообщения (только фото/стикер) пропускаются.
